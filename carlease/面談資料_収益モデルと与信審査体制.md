# StudentCarLease 面談資料

**テーマ:** 収益モデルの実績データ／与信審査体制の詳細
**対象サービス:** StudentCarLease（北海道の学生向け月額定額カーリース）
**作成:** St.Arkid
**面談予定:** 7月末頃

---

## 0. はじめに（本資料の位置づけ）

現在サービスは北海道大学を中心にパイロット運用を開始し、**すでに3台を貸し出し中**です。本資料の数字は、

- **【実績】** … 車両調達価格・月額料金・貸出台数など、すでに確定・稼働している値
- **【想定】** … 今後の稼働台数・成約ペースなど、拡大時の見込みに基づく値

を明示して記載しています。面談では、この実績とユニットエコノミクスをもとに、拡大時の収益像を議論できればと考えています。

※ 任意保険は本モデルの原価には含めていません（別途検討項目）。

料金体系はLP掲載のとおり以下2プランです。

| プラン | 月額 | 内容 |
|---|---|---|
| 個人専用プラン | **15,000円** | 学生1名が車1台を専有。自賠責・車検・税金・スタッドレス込み |
| シェア駐車場プラン | **5,000円〜** | 大学・寮の駐車場に常設した車をアプリ予約でシェア利用 |

## 1. 収益モデルの実績データ

### 1-1. 仕入れ（車両調達）価格

北海道仕様（4WD・スタッドレス）の軽・コンパクト中古車を、**1台あたり10万円**で調達しています。低価格帯の中古車を厳選し、自社管理することで、極めて低い初期投資でカーライフを提供できるのが最大の強みです。

| 項目 | 金額（1台あたり） | 区分 |
|---|---|---|
| **車両調達価格** | **100,000円/台** | 【実績】 |

> 車両価格が低いため、**下取り残価をゼロと保守的に見ても投資回収が早い**のが特徴です。整備・登録・スタッドレス等の付随費用が生じる場合も、後述のとおり数ヶ月で吸収できます。

### 1-2. 貸出（月額）価格と月次コスト

**個人専用プラン（月額15,000円）を基準としたユニットエコノミクス（任意保険を除く）**

| 項目 | 月額換算 | 区分 |
|---|---|---|
| **売上（月額）** | **+15,000円** | 【実績】 |
| 車両償却（100,000円 ÷ 36ヶ月） | −2,778円 | 【実績】 |
| 自動車税・重量税（月割） | −1,200円 | 【実績】 |
| 定期メンテ・消耗品積立 | −1,500円 | 【想定】 |
| **原価 合計** | **−5,478円** | |
| **単体粗利** | **+9,522円/月** | |

> **ポイント：1台あたり月間 約9,500円の黒字。粗利率は約63%です。**
> 車両調達が10万円と低いため、**1台あたり約10〜11ヶ月で調達コストを回収**でき、以降はほぼ利益として積み上がります。

### 1-3. 現在の実績（3台稼働中）

| 項目 | 数値 | 区分 |
|---|---|---|
| 貸出台数 | **3台** | 【実績】 |
| 月間売上 | 3台 × 15,000円 = **45,000円/月** | 【実績】 |
| 月間粗利 | 3台 × 9,522円 = **約28,500円/月** | 【実績】 |
| 投下資本（車両） | 3台 × 100,000円 = **300,000円** | 【実績】 |
| 投資回収 | 約10〜11ヶ月で全額回収の見込み | 【想定】 |

> すでに3台が稼働し、**月次で黒字を出しています。** この単位あたりの経済性を、台数を増やすことでそのまま拡大できるのがこのモデルの要点です。

### 1-4. 拡大シミュレーション

現在の3台のユニットエコノミクスを台数で伸ばした場合の見込みです。

| 稼働台数 | 月間売上 | 月間粗利 | 車両投下資本 |
|---|---|---|---|
| 3台（現在） | 45,000円 | 約28,500円 | 300,000円 |
| 10台 | 150,000円 | 約95,000円 | 1,000,000円 |
| 30台 | 450,000円 | 約285,000円 | 3,000,000円 |
| 50台 | 750,000円 | 約476,000円 | 5,000,000円 |

> - 車両価格が低いため、**台数拡大に必要な資金負担が小さい**（50台でも車両投資500万円）
> - 各台が約10ヶ月で自己回収するため、回収した資金を次の車両調達に回す**再投資による自己増殖が可能**
> - 将来的にシェア駐車場プラン（1台を複数人で共有）を加えれば、同一車両の売上をさらに積み増せる

### 1-5. 面談で共有できる実績の現在地

- ✅ 車両調達価格（100,000円/台）… パイロット車両で確定【実績】
- ✅ 月額料金（15,000円）… 稼働中の契約で確定【実績】
- ✅ 貸出台数（3台）… 稼働中・月次黒字【実績】
- 🔄 拡大ペース・稼働率 … 反響をもとに更新中
- 🔄 シェアプランの経済性 … ローンチに合わせて計測開始

## 2. 与信審査体制の詳細

一般カーリースが「学生」を審査対象外とするなか、当社は**学籍情報を信用の担保に置き換える独自の与信モデル**で対応します。

### 2-1. 学生の審査基準

金融履歴（クレジットスコア）に依存せず、以下の多面的スコアで判定します。

| カテゴリ | 審査項目 | 確認方法 |
|---|---|---|
| **在籍信用** | 大学・学部・学年、在学証明 | 学籍番号＋在学証明書のアップロード（アプリ） |
| **本人確認（KYC）** | 顔写真付き本人確認、なりすまし防止 | eKYC（本人確認書類＋セルフィー照合） |
| **支払い能力** | 仕送り／奨学金／バイト収入の区分 | 自己申告＋（必要に応じ）保護者連絡先 |
| **利用目的** | 通学・バイト・日常利用の妥当性 | 申込時アンケート |
| **運転適性** | 免許取得時期、免許証の種別・違反歴 | 免許証アップロード |

**スコアリングの考え方**
- 各項目を点数化し、**合格ライン以上で自動承認／グレーゾーンは目視審査**の2段階。
- 北海道大学をはじめとする在籍情報は「卒業後に安定就労が見込める＝将来の信用」として高く評価。
- 学生の**保証人不要**を実現するのが狙い（LP掲載の「保証人不要・来店不要」に対応）。

### 2-2. 運転実技の5段階評価とリスク連動プライシング

金融履歴では測れない「事故リスク」を、**実際の運転を見て評価する**ことで直接コントロールします。任意保険を前提にしない本モデルでは、この実技評価がリスク管理の中核です。

**評価の仕組み**
- 契約前に、運営者（代表）が申込者の運転に同乗・確認し、**5段階でスコアリング**します。
- 評価軸は、車両感覚・危険予測・車庫入れ／狭路・冬道（雪道・凍結路）対応・法規遵守などです。
- この5段階の評価に応じて、**契約時の頭金**と、**全損時に利用者が負担する弁済額**を決定します。

**5段階評価と条件の連動（例）**

| 評価 | 運転レベルの目安 | 頭金 | 全損時の負担額 |
|---|---|---|---|
| ★5 | 熟練・危険予測も的確 | 最小（免除〜少額） | 小さく設定 |
| ★4 | 安定して安全 | 少額 | 小さめ |
| ★3 | 標準的 | 標準 | 標準 |
| ★2 | やや不安・要注意 | やや高め | 高め |
| ★1 | リスク大 | 高め、または要再評価・条件付き | 高め、または契約見送り |

> **考え方：うまい人ほど頭金・全損時負担が軽く、リスクが高い人ほど頭金・弁済額で担保する。**
> これにより、任意保険に頼らずとも、①優良ドライバーには魅力的な条件を提示しつつ、②リスクの高い利用者からは事前に担保を取り、全損時の損失（最大でも車両価格10万円）を利用者負担でカバーできます。運転レベルは低リスク側への誘導（安全運転インセンティブ）としても機能します。

**評価体制のスケール（ライセンス制度）**
- 現在は運営者（代表）自身が全申込者の運転を評価しています。
- 台数拡大で運営者の**手が回らなくなった場合に備え、ライセンス制度を用意**します。
- **運転を見慣れている自動車部員**を評価者として認定（ライセンス付与）し、代表に代わって実技評価を担当してもらう体制です。
- 評価基準を標準化・研修することで、評価者が増えても**5段階評価の質と一貫性を維持**しながら審査キャパシティを拡張できます。

### 2-3. 事故・貸し倒れリスクの低減策

**A. 入口（審査・契約段階）**
- **運転実技の5段階評価**（前項2-2）に応じて頭金・全損時弁済額を設定し、事前に担保
- eKYCによるなりすまし防止で、契約者と運転者の一致を担保
- 運転歴・違反歴に応じたプラン制限（新規免許者はシェアプラン優先など）
- 電子署名による契約で、利用規約・免責事項への同意を明確化

**B. 運用（利用中）**
- 車両調達が10万円と低いため、**万一の全損でも損失額が限定的**（1台=最大10万円）
- 事故時の**利用者自己負担ルール**を契約で明確化し、モラルハザードを抑制
- アプリでの**利用状況モニタリング**（予約・返却・走行の記録）による異常検知
- シェア車両は駐車場常設のため、**車両の所在が常に把握可能**
- ※ 任意保険の付保（利用者付保／フリート契約）は今後の検討項目

**C. 出口（延滞・回収）**
- 月額はアプリ内決済で**自動引き落とし＋延滞アラート**
- 延滞発生時は段階的に、①アプリ通知 → ②保護者連絡 → ③利用停止（アプリで遠隔的に予約停止）
- 車両は自社所有のため、最終的な**車両回収の実行が容易**（購入・ローンと異なりリース会社が所有権を保持）

**D. リスク分散の全体像**
1. **低単価でリスク限定**（1台10万円＝損失の上限が小さい）
2. **審査で予防**（貸し倒れ・不適格者）
3. **自己負担ルールで抑制**（モラルハザード対策）
4. **アプリで監視・制御**（延滞・不正利用）
5. **所有権保持で回収**（最終的な資産保全）

### 2-4. マッチングアプリの実装版（仕様）

LPの「4ステップ（登録→審査→契約→受取）」を実装するアプリの仕様概要です。

**① 学生ユーザー向け機能**
- 学籍番号・在学証明のアップロード、eKYC本人確認
- 与信審査ステータスの表示（申請中／承認／要追加書類）
- プラン・車種・利用開始日の選択
- 電子署名による契約締結
- **月額決済・支払い履歴の管理**
- シェアプランの**車両予約カレンダー**（空き状況→予約→解錠）
- トラブル・サポート窓口（アプリ内チャット）

**② 運営（St.Arkid）向け管理機能**
- 申込一覧と**与信スコアの自動判定＋目視審査キュー**
- 車両台帳（所在・整備履歴・車検期日・保険状況）
- 稼働率・売上・延滞状況のダッシュボード
- 事故・トラブルの受付とステータス管理
- 残価・再販管理（3年後の入替計画）

**③ マッチングの核となる仕組み**
- **需要（学生の希望プラン・エリア・利用開始日）** と **供給（在庫車両・シェア駐車場の空き）** を突き合わせて最適配車
- シェアプランでは、同一駐車場・近隣キャンパスの学生をグルーピングし、**1台の稼働を最大化**
- 審査〜契約〜配車をアプリ内で完結（LPの「最短1週間でスタート」に対応）

**④ 実装ステータス【想定／現状】**
- 🔄 申込・eKYC・与信フロー … プロトタイプ実装中（現在はLPフォームで先行受付を代替）
- 🔄 シェア予約・解錠 … シェアプランのローンチに合わせて実装予定（LP上は "Coming Soon"）
- ✅ 問い合わせ・先行受付 … LP申込フォーム＋バックエンド（Cloudflare Worker）で稼働中

## 3. 面談で議論したいポイント

1. **拡大ペース** … 現在3台の実績を、どの速度で何台まで伸ばすか（資金・車両調達の計画）
2. **投資回収と再投資** … 約10ヶ月で回収した資金を次の車両に回す自己増殖モデルの是非
3. **与信・運転評価** … 学籍スコアリングの合格ラインと、運転実技5段階評価に連動する頭金・全損時弁済額の設定、評価者ライセンス制度（自動車部員の活用）の運用
4. **アプリ** … シェアプラン（解錠・予約）実装の優先度とローンチ時期
5. **事故リスク** … 任意保険の付保方針（利用者付保／フリート契約）の要否
