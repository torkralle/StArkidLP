Typing Run

タイピングラン単語を打って、障害物をこわせ！英単語のタイピングゲーム

「タイピングラン」は、前から来る障害物に書かれた英単語を、ランナーがぶつかる前に打ってこわしていくタイピングゲームです。英単語（共通テスト〜ビジネス英語）と医学英語（4,600 語以上）の 2 モード・3 段階のむずかしさ。英字だけなので、スマホの画面キーボードでも遊べます。

App Store・Google Play 近日公開 ブラウザで遊ぶ（Web 版）

状態: アプリは近日公開・Web 版は公開中 ／ 対応: iPhone・Android・ブラウザ ／ 価格: 無料（アプリは広告あり・「広告を消す」買い切り、Web 版は広告なし） ／ 言語: 日本語・英語ほか 7 言語 ／ 提供: 株式会社St.Arkid

タイピング英単語医学英語ランゲームオフライン

English・Español・Português・Deutsch・한국어・繁體中文

遊び方

  1. 「英単語」か「医学英語」と、むずかしさ（やさしい・ふつう・むずかしい）を選んでスタート。
  2. 前から来る障害物に単語が書いてあります。ランナーがぶつかる前にその単語を打つと、障害物をこわせます。
  3. 3 回ぶつかると終わり。進むほど速くなります。結果画面で WPM・正確さ・ぶつかった単語を確かめられます。

こんな人におすすめ

  • スマホでもタイピングと英単語を楽しく練習したい人
  • 医学英語の用語に、ゲームで手を慣らしたい医療系の学生
  • ログインやガチャなしで、気軽に自己ベストを競いたい人

よくある質問

料金はかかりますか？

無料で遊べます。iPhone・Android 版は広告が表示されますが、買い切りの「広告を消す」で消せます。ブラウザで遊ぶ Web 版は広告・課金がありません。

どうなったら終わりですか？

障害物に 3 回ぶつかると終わりです。こわした単語の文字数・コンボ・速さでスコアが決まり、モードとむずかしさごとにベストを記録します。

記録はどこに保存されますか？

自己ベストと設定は端末（Web 版はブラウザ）の中だけに保存し、外へ送りません。機種変更では引き継げません。
