「コメミ」プライバシーポリシー

制定日: 2026年11月15日

株式会社St.Arkid（ST.ARKID, K.K.、以下「当社」）は、スマートフォン用アプリ「コメミ」（以下「本アプリ」）における利用者の情報の取り扱いを次のとおり定めます。

1. YouTube API サービスの利用

本アプリは、YouTube API サービス（YouTube Data API v3）を使って、利用者が指定した YouTube 動画の情報（タイトル・チャンネル名・長さ・サムネイル画像）と公開コメントを取得します。本アプリを使うことで、利用者は YouTube 利用規約（https://www.youtube.com/t/terms）に同意したものとみなされます。YouTube API サービスを通じて扱われる情報には、Google プライバシーポリシー（https://policies.google.com/privacy）が適用されます。

本アプリは利用者の Google アカウント・YouTube アカウントにログインせず、それらのアカウントの情報にアクセスしません。

2. 取得する情報と使いみち

情報内容使いみち保存場所・期間
動画の URL・動画 ID利用者が貼り付けたり共有したりした YouTube 動画の URLYouTube API サービスに送り、その動画の情報とコメントを取得するためGoogle（YouTube API サービス）に送信されます。当社のサーバーには送りません
動画の情報と公開コメントタイトル・チャンネル名・長さ・サムネイル、公開コメントの本文・投稿者の表示名・いいね数・投稿日時・返信機内などオフラインでもコメントを読めるようにするため利用者の端末の中だけ。取得から 30 日で自動的に削除します。利用者はいつでも一覧から削除できます

本アプリは、氏名・メールアドレス・電話番号・連絡先・写真・位置情報・広告識別子を取得しません。アクセス解析・広告・クラッシュ報告のツールも使っていません。当社は利用者の情報を受け取らず、第三者に提供・販売しません。

本アプリは動画そのもの（映像・音声）を保存・再生しません。動画は YouTube アプリまたは YouTube のサイトで再生されます。

3. 端末に保存したデータの削除

  • 一覧の動画を左にスワイプすると、その動画のコメントを削除できます。
  • 取得から 30 日たったデータは、次にアプリを開いたときに自動で削除されます。
  • 本アプリを削除すると、端末に保存したデータはすべて消えます。

YouTube API サービスがアクセスできる利用者の情報はありませんが、Google のアカウント設定（https://security.google.com/settings/security/permissions）から、アプリによるアクセスを確認・解除できます。

4. 子どもの利用

本アプリは、13 歳未満の子どもを対象としていません。

5. 改定

当社は、必要に応じて本ポリシーを改定します。改定後の内容は、このページに掲載した時点から効力を持ちます。
