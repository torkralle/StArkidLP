第1条（本アプリの内容）

本アプリは、YouTube API サービスを使って YouTube 動画の公開コメントを取得し、端末に一時的に保存して、オフラインでも読めるようにする道具です。本アプリは動画そのものを保存・再生しません。

本アプリは YouTube および Google LLC が提供・後援・承認するものではありません。

第4条（保存したコメント）

  2. 保存したコメントは、取得から 30 日で自動的に削除されます。最新の内容が必要なときは取り直してください。
  3. YouTube 側でコメントが削除・非公開になった場合や、YouTube API サービスの利用上限に達した場合などは、取得できないことがあります。
