Gmail Multi MCP プライバシーポリシー

制定日: 2026年10月24日

English version below

St.Arkid(ST.ARKID, K.K.、以下「当社」)は、Gmail Multi MCP(以下「本アプリ」)における利用者の情報の取り扱いを次のとおり定めます。本アプリは、利用者が自分のコンピューター上で動かし、複数の Gmail アカウントを Claude などの AI アシスタントから扱えるようにするツール(MCP サーバー)です。

1. 取得する情報と権限

本アプリは、利用者が Google アカウントで許可した場合に限り、Gmail API を通じて次の権限を使います。

  • https://www.googleapis.com/auth/gmail.readonly: メールの検索、メール・スレッドの本文とヘッダー、ラベル一覧の読み取り
  • https://www.googleapis.com/auth/gmail.compose: 下書きの作成(返信の下書きを含む)

本アプリはメールを送信しません。メールやラベルの削除・移動もしません。

2. 情報の使い方

Gmail のデータは、利用者が AI アシスタントに頼んだ操作(メールの検索、本文の表示、下書きの作成など)を行うためだけに使います。広告の配信、データの販売、利用者の信用力の判断、当社による AI モデルの学習には使いません。

3. 情報の保存場所

本アプリは利用者のコンピューター上だけで動きます。当社はサーバーを持たず、利用者の Gmail のデータや認証情報を当社が受け取ることはありません。

  • OAuth のリフレッシュトークンとアクセストークンは、利用者のコンピューターの設定フォルダ(~/.config/gmail-multi-mcp/)に、本人だけが読めるファイルとして保存します。
  • メールの内容は本アプリが保存することはなく、操作のたびに Gmail API から取得します。

4. 第三者への提供

本アプリが取得したメールの内容は、利用者が操作を頼んだ AI アシスタント(例: Anthropic 社の Claude)にだけ渡されます。AI アシスタント側での取り扱いは、その提供者のプライバシーポリシーに従います。当社がこれ以外の第三者に Gmail のデータを提供することはありません。ただし、法令に基づく場合を除きます。

5. Google API サービスのユーザーデータに関するポリシー

本アプリが Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

6. 許可の取り消しとデータの削除

  • 本アプリへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
  • 利用者のコンピューターから ~/.config/gmail-multi-mcp/ フォルダを削除すると、保存されたトークンはすべて消えます。

7. 安全管理

トークンを保存するフォルダとファイルは、ほかのユーザーから読めない権限(フォルダ 700、ファイル 600)で作成します。Google との通信はすべて HTTPS で暗号化されます。

8. 本ポリシーの変更

当社は必要に応じて本ポリシーを変更します。変更後の内容はこのページでお知らせします。

Privacy Policy

Gmail Multi MCP Privacy Policy

Effective date: October 24, 2026

This Privacy Policy explains how St.Arkid (ST.ARKID, K.K., "we") handles user information in Gmail Multi MCP (the "App"). The App is a tool (an MCP server) that users run on their own computer to let AI assistants such as Claude work with multiple Gmail accounts.

1. Data accessed and scopes

Only when the user grants permission with their Google account, the App uses the Gmail API with the following scopes:

  • https://www.googleapis.com/auth/gmail.readonly: to search messages and read message and thread contents, headers, and labels
  • https://www.googleapis.com/auth/gmail.compose: to create drafts, including reply drafts

The App never sends email, and never deletes or moves messages or labels.

2. How we use the data

Gmail data is used only to perform the actions the user asks the AI assistant to take, such as searching messages, showing message contents, and creating drafts. It is not used for advertising, sold, used to determine creditworthiness, or used by us to train AI models.

3. Where data is stored

The App runs only on the user's own computer. We operate no server for the App, and we never receive users' Gmail data or credentials.

  • OAuth refresh and access tokens are stored on the user's computer in ~/.config/gmail-multi-mcp/, in files readable only by that user.
  • The App does not store message contents; it fetches them from the Gmail API for each request.

4. Sharing with third parties

Message contents retrieved by the App are passed only to the AI assistant the user is using (for example, Claude by Anthropic), as requested by the user. That provider's privacy policy governs how it handles the data. We do not share Gmail data with any other third party, except as required by law.

5. Google API Services User Data Policy

The App's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access and deleting data

  • Users can revoke the App's access at any time from Third-party apps & services in their Google Account.
  • Deleting the ~/.config/gmail-multi-mcp/ folder from the user's computer removes all stored tokens.

7. Security

The token folder and files are created with permissions that other users cannot read (700 for the folder, 600 for files). All communication with Google is encrypted over HTTPS.

8. Changes to this policy

We may update this policy as needed. Changes will be posted on this page.
